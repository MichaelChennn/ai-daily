# 网页 design system

issue #43 重设计后的网页样式：每期页（含 beta 页）、归档页、信源页。这些页面都用 `web/src/layouts/PressLayout.astro`，样式全在 `web/src/styles/press.css`。生成过程页和 404 还在用旧的 `Layout.astro`，改造时照这份文档做。

数值以 `press.css` 开头的 token 为准。改了 token 要同步改这份文档；反过来也一样。

## 原则

- 只有页面内容，不加顶栏。左上角放文字标，左侧是导航条，语言和日夜按钮在左下角，其余链接（GitHub、RSS、生成过程、Beta 版）都放在页脚。
- 卡片的动效只用整像素平移，不旋转，不缩放，不做 3D，否则文字会发虚。也不加高光。
- 厂商 logo 一律用原色。正文不用浅灰色。
- 交互连续点击时必须立即响应。不加加载进度条。
- 新页面不要用 Tailwind：它的 preflight 会改默认样式。

## 颜色

日间是灰绿色调，夜间是墨黑色调。没手动选过主题时跟随系统，手动选择存在 `localStorage.theme` 里。

| token | 日间 | 夜间 | 用途 |
|---|---|---|---|
| `--paper` | `#E8EBE3` | `#16171A` | 页面底色 |
| `--card` | `#F5F7F2` | `#202226` | 卡片、弹层 |
| `--ink` | `#161A15` | `#EDEBE6` | 标题、正文、图标 |
| `--ink-2` | `#333A31` | `#C9C6BF` | 摘要正文 |
| `--muted` | `#626A5E` | `#8E8B85` | 日期、类型、页脚、统计标签 |
| `--line` | `rgba(22,26,21,.10)` | `rgba(237,235,230,.12)` | 描边、分隔线、弹层行的悬停底色 |
| `--chip` | `#D9DED2` | `#2E3035` | logo 加载前显示首字母时的底色 |

夜间值在 `press.css` 里写了两遍：一遍在 `prefers-color-scheme: dark` 里，一遍在 `:root[data-theme="dark"]` 里。改的时候两处要一起改。

## 阴影

| token | 用途 |
|---|---|
| `--shadow` | 卡片静止时 |
| `--shadow-hi` | 卡片悬停抬起时 |
| `--shadow-pop` | 来源弹层 |

日间阴影都用墨绿色 `rgba(22,26,21,…)`，夜间用纯黑。

## 字体和字号

| token | 字体 | 用途 |
|---|---|---|
| `--f-title` | Noto Serif SC（思源宋体），只加载 700 | 所有标题、时间轴标签、文字标 |
| `--f-body` | Inter，中文用苹方或思源黑体 | 正文、摘要、页脚 |
| `--f-mono` | JetBrains Mono | 日期、出版方、编号、统计数字 |

字体都从 Fontsource 自托管，在 `press.css` 开头 `@import`。宋体只加载了 700，所以标题的字重一律写 700。

| token | 大小 | 衬线标题 | 其他 |
|---|---|---|---|
| `--fs-xl` | 24px | 分节标题（每期的分区、归档的月份、信源的分组） | — |
| `--fs-l` | 20px | 新闻卡标题、左上角文字标 | — |
| `--fs-m` | 15px | 快讯标题、书脊、归档卡、信源名称、时间轴标签 | 正文、摘要、信源统计数字 |
| `--fs-s` | 13px | — | 页脚、弹层里的行、「这天没有日报」、提示条 |
| `--fs-xs` | 12px | — | 元信息行、日期、类型、统计标签、分节编号 |
| `--fs-2xs` | 11px | — | `.off-tag`、来源堆的「+N」 |

衬线标题只有三档字号：24、20、15。例外有两处：
- 手机上新闻卡标题是 19px。
- logo 里的首字母是 10px（来源堆小圆点里是 9px），大小跟着 logo 的尺寸定。

## 版面和间距

| token | 值 | 用途 |
|---|---|---|
| `--w-read` | 720px | 主栏和页脚的宽度（每期页、归档页） |
| `--w-wide` | 1056px | 信源页的主栏和页脚（`main.wide` / `footer.wide`），1200px 及以上才生效 |
| `--pad-l` / `--pad-r` | 24 / 24px，手机 44 / 16px | 主栏和页脚的左右内边距；页脚分隔线也用它们和卡片对齐 |
| `--space-section` | 64px | 每期页各分区之间 |
| `--space-group` | 40px | 归档的月份、信源的分组之间；提示条下方 |
| `--gap` | 12px | 卡片之间（上下、网格） |
| `--strip-h` | 48px | 书脊高度（新闻卡收起后、归档卡） |
| `--stick-top` | 16px | 书脊吸顶的位置 |

`press.js` 按 px 读取 `--gap`、`--strip-h` 和 `--stick-top`，这三个 token 只能写成 px 值。

## 组件

组件在 `web/src/components/press/`，页面脚本在 `web/src/scripts/`。

### 文字标

左上角的「AI 科技日报」：20px 宋体，`position:fixed`。手机上改成 absolute，跟着页面滚走。以后会换成图形 logo。

### 左侧条（`Rail`、`SectionRail`）

照 Stripe Press 的菜单做，参数照它的源码：
- 位置是 `--rail-x`：`calc(10px + 1vw)`，手机上是 10px。
- 一根刻度占 13px（`--tick-pitch`），最多同时显示 20 根（`--W`），超出的部分可以滚动。

两种用法：
- **`Rail`**（每期页）：一根刻度代表一个自然日，最新的一期在最下面。没有日报的日子也照样占一根刻度，但不能点，标签写「这天没有日报」。上方是向下的箭头「回到最新一期」，只在当前不是最新一期时出现。脚本是 `press.js`。
- **`SectionRail`**（归档、信源）：一根刻度代表一个月或一个分组。点击后滚到对应位置，滚动时高亮当前所在的那根。上方是向左的箭头「回到日报」，一直显示（`.rail.back`）。脚本是 `section-rail.js`。

刻度下方是归档、信源两个图标（`RailIcons`），当前页面的图标常亮（`aria-current`）。

悬停时：
- 所有标签都显示，主栏和页脚的不透明度降到 0.12。
- 刻度按 Dock 方式放大：`scaleX = max(1, cos(距离 / 刻度总数 × π) × 2 + 2.5)`。

手机上不显示标签，改为按住拖动，手指位置显示气泡 `.bubble`，用法像通讯录的字母索引条。

### 分节标题 `.sec-h`

24px 宋体。每期页的分区标题前面有等宽编号（`01`）。归档的月份、信源的分组标题样式相同，但不编号。

### 卡片 `.face`

三种卡片共用的外壳：`--card` 底色、1px `--line` 描边、`--r-card` 圆角、`--shadow` 阴影。

悬停抬起：`translateY(--lift)`（-3px），阴影换成 `--shadow-hi`，时长 `--dur-lift`（.25s），缓动 `--ease`。以下情况不抬起：
- 触屏
- 减少动态效果
- 新闻卡处于书脊状态

新闻卡由 `press.js` 加 `.hov` 类来触发抬起；归档卡和信源卡直接用 `:hover`，外面套一层 `(hover:hover) and (pointer:fine) and (prefers-reduced-motion:no-preference)`。

### 新闻卡和书脊叠放（每期页）

- **展开状态 `.full`**：
  - 元信息行 `.meta`：16px logo、等宽的出版方、日期。有多个来源时，右端是来源堆。
  - 20px 标题，链接到第一个来源。
  - 摘要。
- **书脊 `.strip`**：卡片滚到顶部时收成 48px 的窄条，只显示 logo 和一行标题，在同一分区内 sticky 叠放。快讯不叠放。

### 带链接的标题

标题悬停时从左往右画出 1px 下划线（.35s），行尾出现 `↗`。箭头 `.arr` 的宽度为 0，所以标题刚好占满一行时，箭头不会单独折到下一行。新闻卡标题、快讯标题、信源名称都用这个效果。

### 来源堆和弹层（`ItemMeta`、`PopList`）

最多叠 3 个 18px 的圆形 favicon，超出部分显示「+N」。悬停时圆点向右散开 2px。悬停或点按会打开弹层 `.pop`，里面列出全部来源：
- 原文标 `↗`，讨论标 `💬`。
- 只有一个来源时，弹层只写「出版方 · 日期」。

信源页的 GitHub Releases 卡复用这个组件：右上角显示仓库 owner 的头像，弹层顶部写「14 个仓库」。

### 快讯 `.briefs`

上下用分隔线隔开的列表。每行左边是 15px 宋体标题，右边只放来源堆，出版方和日期都在弹层里。往上滚到视口 80% 左右时，这一行的摘要展开；滚回去后收起。

### 归档卡 `.arc`

固定为书脊样式，48px 高：logo、一行标题，右侧是等宽日期（「11月7日」，不写年份和星期）。整张卡链接到那一期，不叠放，卡片间距是 `--gap`。

### 信源卡 `.src`

1200px 及以上三列，599px 以下一列，中间两列。所有卡片等高：
- 名称和类型都只占一行，超长时截断加省略号，完整名称放在 `title` 属性里。
- 统计栏固定在卡片底部。
- 停用的信源，「暂不抓取」这一行和统计栏一样高（41px）。

名称是 15px 宋体，链接到信源；logo 16px，和名称垂直居中。停用的信源排在本组最后，内容降到 0.6 不透明度，名称右侧加 `.off-tag`。

### 标签 `.off-tag`

小号描边标签：11px 等宽字体、`--line` 描边、`--r-tag` 圆角、`--muted` 字色。目前只用来标「已停用 / Paused」。

### 统计栏 `.stats`

三栏居中：上面是 12px 的 `--muted` 标签，下面是 15px 等宽数字，用 `tabular-nums`。标签不换行；某一栏的标签放不下时，那一栏会自动变宽。

### 页脚（`PressFooter`）

最上方是一条 1px 分隔线，左右和卡片对齐。

- **每期页**两行：
  - 第一行左边是「本期由 X 编辑 · 生成过程 · Beta 版」，右边是 GitHub、RSS 图标。
  - 第二行是更新时间和许可。
  - 没有内容的部分不渲染。
- **没有对应期的页面**（`footer.solo`）只有一行：左边是更新时间和许可，右边是图标。
  - 参数 `note` 加在这一行最前面，比如信源页的「统计最近 30 期」。
  - 参数 `wide` 让页脚和信源页主栏一样宽。

### 语言和日夜按钮

固定在左下角，18px 大小，平时不透明度 0.3，悬停时变为 1。日夜按钮在下，语言按钮「文/A」在上，点击直接换到另一种语言。新页面加载时两个字交换位置，只平移，缓动用 `--ease-swap`。

### 提示条 `.notice`

左侧 2px 竖线，13px 的 `--muted` 文字。用于两种情况：这期还没有英文版，或者显示的是退回的版本。

## 动效

| 动效 | 参数 |
|---|---|
| 首次进入页面 | 左侧条的刻度从 `scaleX(0)` 依次展开，第 i 根延迟 `i × .1 + .4s`；首屏的卡片同时从上往下依次渐入（`Drop`：从上方 18px 处落到原位，.9s，`--ease`），和刻度同速往下走 |
| 在两期之间跳转 | 跨页面 view transition，.32s；左侧条不再播放入场动画（`.rail.still`） |
| 在每期页和归档页之间跳转 | 只有左侧条重播入场动画（sessionStorage `press-switch`） |
| 卡片悬停 | 抬起 3px，.25s |
| 标题悬停 | 下划线 .35s，`↗` .2s |
| 左侧条悬停 | 标签向右滑入 5px（.2s），刻度 Dock 放大（.2s），主栏淡出（.3s） |
| 来源弹层 | 向下滑入 4px，.16s |
| 快讯摘要 | 展开和收起 .5s，`--ease` |

`--ease` 是 `cubic-bezier(.2,.7,.2,1)`，大多数动效都用它。

## 响应式断点

| 宽度 | 变化 |
|---|---|
| ≤ 599px | 信源卡改为一列 |
| ≤ 899px | 手机布局：左侧条贴边，不显示标签，改为拖动；文字标改为 absolute；内边距改为 44 / 16px；卡片内边距缩小；新闻卡标题 19px |
| 900–1199px | 主栏和页脚不居中，左边距 220px，给左侧条的标签留位置；信源卡两列 |
| ≥ 1100px | 左侧条图标和标签之间从 8px 改为 10px（照 Stripe） |
| ≥ 1200px | 主栏居中；信源页宽版、三列 |

## 减少动态效果

系统开启「减少动态效果」时：
- 没有入场动画，没有悬停抬起，也没有跨页面的 view transition。
- 快讯摘要直接展开或收起，不播放过渡。
- 悬停左侧条时，只显示指针下的那个标签，直接出现，不播放滑入。

## 新页面接入清单

1. 用 `PressLayout`。样式只用 `press.css`：通过 `import x from "…css?url"` 加手写 `<link>` 引入，不要在 JS 里直接 `import` CSS，否则会把旧页面的 Tailwind 一起带进来。
2. 页面结构：`.logo` + 左侧条（`SectionRail`，或者不需要时只放 `RailIcons`）+ `main` + `PressFooter`。
3. 颜色、字号、圆角、阴影都用 token。需要新的值时，先确认现有档位确实不够，再在 `:root` 里加 token，并更新这份文档。
4. 卡片用 `.face`，标题用对应档位的宋体字号，日期和数字用 `--f-mono`。
5. 日夜两种主题、三种宽度（1440、1024、390）都要截图检查；还要打开「减少动态效果」检查一遍。
